Built a VS Code-style dock (`#dock`, last child of `#terminal-container`; bottom by default, `.dock-right` flips it) hosting Decisions, Structure, Prompts, Activity and Feedback one tab at a time; those rows, GitHub and the Frame group left the sidebar nav. State (open / position / tab / size) is the pure `src/renderer/dock/dockState.js` (27 tests), the host `dock.js` applies it, persists it app-wide under `frame-dock`, and refits terminals only on open / close / side change / drag-release — never per frame.
Why this path: a region, not a view mode — `viewMode` and `getActiveSurface()` still describe the center; the dock reports itself through `dock.onChange`. Rejected: two hosts for the structure map (overlay for ⌘K + dock), a one-row "Project" nav group, per-panel width overrides in three CSS files (one `.dock-hosted` rule instead), listing icons twice (the status bar reads `DOCK_TABS`).
Entry points share one seam: registered commands `dock.toggle` (⌘J), `dock.decisions/structure/prompts (⌘⇧L)/activity/feedback`, `dock.moveRight/moveBottom`, `sidebar.github` (⌘⇧G), `settings.openProject`. The native View menu sends the id over the new `RUN_APP_COMMAND` (not `RUN_COMMAND`, which types into a terminal); status-bar icons and the palette run the same ids. `TOGGLE_HISTORY_PANEL`, `panel.togglePrompts`, `panel.toggleGitHub`, `showDecisions`, `showStructureMap`, `structureMap.init()` and the `#structure-map-overlay` are gone; `PANEL_REGISTRY` is `{ claude }`.
GitHub renders inside the sidebar's fourth rail tab (`revealSidebarTab('github')` calls `githubPanel.show()`; `.visible` no longer gates it). Project Settings is one ungrouped row at the nav's foot carrying `id="project-settings-btn"` so `specDrivenHint` keeps its anchor.
Rules for future work: a new dock surface is a `DOCK_TABS` entry (`mount/unmount/refit`) plus one registered command; a re-parented panel goes through `panelTab()`; anything that changes the center's size calls `terminal.fitTerminal()` once, after the change settles; a View-menu item is one more `sendAppCommand(id)`, never a new IPC channel.
Followup: `panels.css` still carries dead `.structure-map-sidebar` / `.node-details` / `.map-control-*` rules.
